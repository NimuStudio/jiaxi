fix(layout): 超宽屏顶栏仍挤 —— 一处重复的 width 覆盖了媒体查询

## 现象
用户 2560 宽的窗口里，「肺癌风险」几乎贴住演示徽标，品牌副标题被压成省略号。

## 根因
globals.css 里有两处 .topbar { width }：
  第 177 行（基础规则，现为 1240px）
  第 5562 行（后来加的一条「防挤压」补丁，也写了 width: 1240px）
媒体查询不提升优先级，于是第 5562 行那条无条件的规则把
@media (min-width: 1800px) { .topbar { width: 1560px } } 整个覆盖掉了 ——
改了半天没反应就是这个原因。

## 改法
- 删掉第 5562 行的 width，只留 gap（宽度交给基础规则和媒体查询）
- 超宽屏（≥1800）顶栏放宽到 1560px、gap 18px，让步骤编号有地方站
- 步骤编号 ≤1799 隐藏；引擎标注 ≤1500 隐藏；品牌副标题 ≤1280 隐藏
- .topbar-nav-btn 加 flex: 0 0 auto，标签永不压缩

## 验证
Edge 无头截图：2560 / 1626 / 1440 / 1280 / 1024 五档，
四个导航标签全部完整、与演示徽标之间有余量；163 测试通过；build 通过。
