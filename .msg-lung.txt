feat(lung): 新增 PLCOm2012 肺癌风险引擎与 /lung 页

老师评审时提的场景：「个别人群基因里肺功能不好，抽烟更易得肺癌，能不能按前几代情况推算概率」。
此前项目只到「相对风险 + 筛查建议」，这一轮补上绝对风险，且每个系数都有出处。

## 模型来源
Tammemägi MC, et al. Selection Criteria for Lung-Cancer Screening.
N Engl J Med 2013;368(8):728-736. PMID 23425165. 系数取自原文表 2（含常数项 −4.532506）
与表注（中心化取值、吸烟强度的 1/x 非线性变换、计算步骤）。

## 实现
- src/lib/risk/plcom2012.ts：11 个 β 逐项对应原文，保留 terms 便于界面解释
- app/lung/page.tsx：11 项输入 + 6 年风险 + 阈值对照（UKLS 1.51% / NLST 1.3455%）
  + 三项贡献 + 年龄越界提示 + 家族史自动读取
- src/lib/risk/lungFamily.ts：家系 → 肺癌家族史（一级/二级分开，二级只给提示不勾选）

## 测试（新增 21 项，总计 143 通过）
- plcom2012.test.ts（14）：3 条独立手算对账（Python 逐项展开）+ 方向性 + 非线性项 + 边界
- lungFamily.test.ts（7）：一级/二级/优先级/旧中文病名/他病/本人

## 界面与文案
- 顶栏加「04 肺癌风险」；1440px 以下隐藏步骤编号并收紧内边距，避免挤到演示徽标
- 登录页与 README 的「2 套指南方程」改为 3
