fix(a11y): 键盘走查——登录页焦点接力、弹层 Esc 作用域、输入框上限与可访问名

键盘逐键走查发现三处问题：

1. 登录页 Tab 一次能展开，但展开瞬间光缝按钮被 visibility:hidden，焦点掉回页面顶部。
   现在展开后若焦点来自光缝按钮（或已丢到 body），自动送进用户名输入框。
   实测：Tab 一次 → 页面展开 → 直接可输入用户名。

2. 下拉打开时按 Esc 会把整个体检弹层一起关掉（想收下拉却收掉了弹层）。
   两次尝试失败：stopPropagation 在 document 冒泡监听之间无效；
   React 合成事件里 stopPropagation 也没能阻止 document 上的监听。
   最终改为在下拉的 effect 里用【捕获阶段】监听 keydown 并 stopPropagation，
   捕获先于弹层的冒泡监听执行。复测：下拉关闭、弹层保留；下拉未开时 Esc 仍正常关弹层。

3. 登录页两个输入框补 maxLength（用户名 32 / 密码 72，与服务端一致）与 aria-label。

同时确认正常：
- 弹层内 Tab 连续 8 次焦点始终在弹层内（焦点陷阱生效）；
- 性别下拉可用「点击打开 → ↓ → 回车」完成选择，选中后弹层不被关闭，徽章同步更新；
- Esc 关闭弹层、下拉的键盘选中不影响弹层状态。

tsc 0 错误，122 测试通过，build 通过，控制台无错误。
