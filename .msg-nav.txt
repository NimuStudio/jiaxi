fix(layout): 顶栏在 1280–1626 区间挤爆，导航标签被演示徽标截断

## 现象
1626 宽的窗口里「肺癌风险」被截成「肺癌风」，一半压在演示徽标下面。

## 原因
顶栏宽度上限 1120px，但里面塞了：品牌 + 副标题 + 四项导航（每项还带 01–04 编号）
 + 演示徽标 + 引擎标注 + 在线状态 + 账号，总宽度超过容器；导航又设了 overflow: clip，
于是最后一个标签被硬切掉。

## 改法（按优先级让位，不再截断标签）
- 顶栏宽度 1120 → 1240px
- 步骤编号只在 ≥1800px 显示（原来 1440 以下隐藏，1626 这种恰好露出来最挤）
- 引擎标注 ≤1500 隐藏，品牌副标题 ≤1280 隐藏
- .topbar-nav-btn 加 flex: 0 0 auto，标签一个字都不许压缩
- 去掉 .topbar-nav 的 overflow: clip（它会在空间不足时直接切掉标签）

## 验证
Edge 无头截图实测 1626 / 1440 / 1280 / 1024 四档，四个导航标签均完整显示、
无重叠无截断；163 测试通过；tsc 0 错误；build 通过。
