review: 修 3 个 bug + 2 处隐患；词表缺口发现转正为脚本

## Bug
1. repairOtherCodes 的 other 回填把 i 每人重置 —— 多人各说一种病时，
   第二个人会拿到第一个人的病名（如「我爸房颤，我妈骨质疏松」两人都变房颤）。
   改为：整段只出现一个 other 且存在具体病名时才回填，否则保留 other。
2. ruleExtract 里 `h.key !== "other" || text.includes(h.text)` 恒真 —— 死条件，删除。
3. 结构模型权重与特征维度不一致时会静默算出 NaN，NaN<0.55 恒为 false → 会被当成
   「高置信度」放行。改为构造时校验维度并抛错，让上层兜底。

## 隐患
4. 决策接口的限流只按 IP：反代后所有用户可能共用同一个 x-forwarded-for，
   会把不相干的人一起限死。改为登录用户按 user id（60 次/10 分钟）、未登录按 IP（20 次/10 分钟）。
5. 评测产物里的 model 字段取自环境变量，换服务但忘改 env 就会记错模型。
   改为实际查询 /v1/models 记录的 id。

## 新增
- scripts/lexicon-gaps.ts + npm run gaps：自动发现「出现但词表没收录」的称谓与病名，
  并单独列出「设计上不支持」的姻亲/曾祖辈（老丈人/公公/舅妈/太奶奶），避免每次重复讨论。
  当前 11 个文件 365 条输入：真缺口 0，不支持 4 条。
- build_extract_dataset.py：训练集若包含已对外报数的留出集，打印警告并点名，
  提醒重训后需要新造封存集。
