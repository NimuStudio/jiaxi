# 准确性怎么保证

> 本文是**唯一数字来源**。其他文档引用指标时请写「见 docs/accuracy.md」，
> 不要各自抄数字——2026-11-09 排查发现 tech-design 与 demo-script 里
> 同一指标出现过 0.952 / 1.000 两个版本，且评测集条数已与文件不符。

## 一、三层分离：不同层用不同的保证手段

| 层 | 内容 | 保证手段 | 不依赖模型 |
|---|---|---|---|
| ① 确定性计算 | FINDRISC / China-PAR / PLCO2012 风险值 | 对齐原始论文公式；边界值、NaN、缺项都有用例；`sanitize()` 兜底 | ✅ |
| ② 抽取 | 口述病史 → 结构化 JSON | 人工标注评测集 + 每次改动跑回归 + 精确率优先 | ❌ 用模型，但有评测集 |
| ③ 判定 | 遗传模式、通知分诊 | 配对评测 + 校准 ECE + 置信度门槛 + 拒答 | ❌ 但可换后端对比 |
| ④ 展示 | 用户看到的结论 | 不确定就不显示；文案写「提示，不是诊断」；缺口用于追问 | ✅ |

**核心原则**：模型只做它不可替代的事（把口语变成结构）。一旦涉及判断，先问
「能不能用规则或可复算的方式做」，不能才交给模型，且必须给出置信度与拒答路径。

## 二、可复现的指标（每次评测自动留痕）

## 三、判定层（遗传模式）的准确性

同一批均衡样本（每类 5 条）配对比较，产物 `ml/out/inheritance_eval.json`：

| 后端 | 准确率 | ECE | 单次延迟 |
|---|---|---|---|
| OpenJev-Q4（18.5 GB） | 40% | 0.401 | 6.3 s |
| 结构逻辑回归（12 维，2.3 KB） | 96% | — | <0.1 s |

**边界**：96% 是合成集上的同分布成绩（训练与测试同源于 `ml/gen_inheritance_eval.py`），
不等于真实家系准确率。真实数据需要医生复核才有意义——没有就不宣称。

## 四、当前已知失败模式（来自口语 v2 产物，14/80 不完全匹配）

| 类型 | 例子 | 现象 |
|---|---|---|
| 称谓混淆 | 「我哥」 | 抽成 paternal-uncle |
| 续句主语丢失 | 「我妈高血压，我哥也是」 | 第二人漏抽 |
| 病种回退 other | 「房颤」「慢阻肺」「老年痴呆」 | 抽成 `other` |
| 多病错挂 | 「爷爷糖尿病，爸爸高血压」 | 高血压挂到爷爷 |
| 口语动词误判 | 「一直在吃药」 | 抽出 `other` |

这五类就是下一轮要修的目标，修完重跑并新增产物文件，**不覆盖旧文件**。

## 五、做不到的（诚实边界）

1. **没有临床验证**：无医生复核、无真实患者随访，所有指标都是工程评测。
2. **没有用户数据回流**：隐私优先，不做埋点式准确率统计。
3. **抽取评测集是自建的**：分布比真实口述窄，指标偏乐观。
4. **合成集只证明「结构可判」**，不证明「真实家系可判」。
