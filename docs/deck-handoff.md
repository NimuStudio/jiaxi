## 2. 设计规范（改之前先读这一节）

### 2.1 版面

- 画布 13.333 × 7.5 in（16:9），**不要改成 4:3**
- 左右安全边距 `M = 0.78 in`，正文宽 `W = 11.773 in`（代码里的 `M` 与 `W` 常量）
- 页头区 0 – 0.82 in；正文从 1.02 in 起；页脚基线 6.90 / 6.96 in

### 2.2 色板

| 名称 | 值 | 用途 |
| --- | --- | --- |
| BG | `#F2F7FC` | 底色基准（实际用生成的背景图） |
| TEXT | `#0F2A44` | 正文/标题深蓝 |
| MUTED | `#4A6B8A` | 说明文字 |
| FAINT | `#8AA3BB` | 注释、图注（最浅一档） |
| LINE / LINE2 | `#DBE7F3` / `#C2D6E9` | 发丝线 / 卡片描边 |
| PRIMARY | `#1A6FB5` | 主蓝（技术路线、链接、强调） |
| RECLAIM | `#0F7C8C` | 「可回收 / 能改」语义色（青） |
| RED | `#C0392B` | **只给每页最重要的那个数字或结论** |
| RED_SOFT | `#FBEAE7` | 红底浅块 |

### 2.3 六个栏目的识别色（全篇一致的定位系统）

| 栏目 | 色相 | 值 |
| --- | --- | --- |
| 01 项目背景 | 琥珀 | `#B06A08` |
| 02 方案与产品 | 青 | `#0D7C8A` |
| 03 技术路线 | 主蓝 | `#1A6FB5` |
| 04 准确性与选型 | 紫 | `#684EBA` |

右缘竖排章节名（背景图内）、页面侧栏面板（背景图内）。

### 2.4 字号（只有三档）

| 层级 | 字号 | 用在哪 |
| --- | --- | --- |
| 页标题 | 29pt 粗体 | 每页主标题（`new_slide()` 里固定） |
| 扉页标题 | 46pt 粗体 | 六张章节扉页 |
| 结论 | 13.5pt 粗体 | 卡片/段落的第一句话 |
| 证据 | 10.0pt | 支撑说明 |
| 注释 | 8.5pt `FAINT` | 图注、样例、口径说明 |
| 页头胶囊 | 8pt | 页头类型标签 |

**不要**再加第 4 个字号：层级只有三档，多加一档就读不出来了。

### 2.5 页头 / 页脚 / 扉页

- 页头（`nav_bar()`）：白色浅带 + 品牌方块「家」+ 中文名/英文名 + 六个栏目名
  + 当前栏目上方一个圆点 + 右端六段章节进度刻度
- 页脚（`footer()`）：一条发丝线 + 品牌小方点 + 「家系 · 家族健康风险量化」+ 页码
- 页码**自动编号**：构建结束后按真实页序填，插页不用手改
- 目录页码也是**反查**出来的（查该章扉页在第几页），插页删页都不用改

### 2.6 动效

- 每页 fade 切页 + 内容按「上到下、左到右」分成最多 3 组入场，**一页最多按两次**
- 关掉入场只留切页：构建时设环境变量 `DECK_ANIM=transitions`
- 已在真机 PowerPoint 放映验证过

### 2.7 讲稿备注

每一页都有备注（PowerPoint 的"演讲者备注"）。内容页 26 条 + 扉页 6 条。
备注是**按顺序贴的**：插内容页要同时在 `NOTES` 列表里插一条，否则后面全部错位。
扉页会被自动跳过（代码里判断 `DIVIDER_SLIDES`）。

## 3. 怎么改

### 改文字

1. 打开 `scripts/build_deck_v2.py`，搜这页标题里的关键词（例如「免费的风险信号」）
2. 改 `para()` / `rich()` 里的字符串
3. 标题里用 `**…**` 包住的部分会渲染成红色强调（`emphasized()` 处理）
4. 重新构建（见第 4 节）

### 改配色

- 栏目色：`build_deck_v2.py` 的 `SECTION_HUES` + `deck_art2.py` 的 `SECTIONS`（两处必须同步）
- 强调红：`RED`
- 改完必须重跑 `deck_art2.py`（背景图里烤进了色相），再跑 `build_deck_v2.py`

### 加一页

```python
s = new_slide(2, "页标题：**红字部分**", icon="chart", sub="副标题", tag="技术 · 补充")
# 在这里画内容；坐标单位为英寸，用 M / W 常量对齐
footer(s, 0)      # 页码会自动填，传什么都行（保留占位即可）
```
然后：① 在 `NOTES` 列表对应位置插一条备注；② 目录页码会自动更新，不用管。

### 换图

- 产品截图：放 `docs/screenshots/`，再在 `deck_art2.py` 的 `browser_frame()` / `laptop_frame()` 里指过去
- 终端图：`docs/deck-assets/shots/`，由 `scripts/deck_shots.py` 生成（内容在 `SHOTS` 字典里）
- 家系图：`scripts/export_tree.py` 生成 SVG → `scripts/svg2png.mjs` 转 PNG

## 4. 素材怎么重新生成

四个脚本，按依赖顺序跑：

```bash
cd pedigree

# ① 背景 / 扉页 / 设备外框（最慢，约 60-90 秒）
python scripts/deck_art2.py

# ② 终端实跑截图（素材改了就重跑）
python scripts/deck_shots.py

# ③ 家系图：DEMO 数据 → SVG → PNG
python scripts/export_tree.py
node scripts/svg2png.mjs docs/deck-assets/tree.svg docs/deck-assets/tree.png 1600

# ④ 出稿
python scripts/build_deck_v2.py
```

### 依赖

| 需要 | 说明 |
| --- | --- |
| Python 3 + `python-pptx` `Pillow` `numpy` | 出稿与画背景 |
| Node + `@resvg/resvg-js` | SVG 转 PNG（`pnpm add -D @resvg/resvg-js`） |
| 微软雅黑 / 思源宋体 | 背景里的中文与等宽字体 |
| LibreOffice Kit | 只用于把 pptx 渲染成 PNG 预览，出稿本身不需要 |

### 输出到别处

```bash
DECK_OUT="家系-答辩-v3.pptx" python scripts/build_deck_v2.py
```
**PowerPoint 打开着成品文件时，构建会报 `PermissionError`**——先关掉，或者用 `DECK_OUT` 输出到别的文件名。

## 7. 已知的坑（都真踩过）

1. **不要手工改 pptx**：整份是脚本生成的，下次构建会覆盖。
2. **PowerPoint 占用文件 → 构建失败**：`PermissionError`，先关 PPT 或用 `DECK_OUT`。
3. **所有形状的默认效果会被清掉**（代码里统一清 `effectLst`），只有卡片走 `card=True` 会带柔和投影。
   自己新画的形状要投影，就用 `soft_shadow()`。
4. **中文竖排不能靠旋转**：CJK 竖排是逐字往下排，把横排文字 `rotate(90)` 会得到横躺的字。
5. **LibreOffice 不支持 svg → png**（`unsupported-format`），SVG 转 PNG 用 `@resvg/resvg-js`。
6. **半调装饰必须用线稿**：拿实心节点 + 文字的产品图做半调，会糊成一坨一坨的脏斑
   （`export_decor.py` 专门画了只有线条的家系图）。
7. **备注按下标贴**：插页要同步插 `NOTES`，否则全部错位。
8. **字体**：全篇用微软雅黑（`EA = "微软雅黑"`）；换机器若没有这个字体，会把版面撑开或换行。
