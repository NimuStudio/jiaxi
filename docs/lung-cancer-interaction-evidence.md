# 肺癌「家族史 × 吸烟」的文献线索（2026-11-05 更新）

> 老师提出「有些家族基因里肺功能不好，抽烟容易得肺癌，可以按前几代推算概率」。
> 本文记录查证过程、拿到的材料，以及结论：**为什么仍然不给数字**。

## 一、查到的来源

| 来源 | 题录 | 状态 |
| --- | --- | --- |
| CKB 肺癌绝对风险模型（ALARM） | Lung Cancer Absolute Risk Models for Mortality in an Asian Population using the China Kadoorie Biobank. JNCI, 2022. PMID 36083018 / PMC9949588 / doi 10.1093/jnci/djac176 | **已拿到正文 + 补充材料（16 页）** |
| 中文交互作用研究 | 肿瘤家族史和吸烟在肺癌发生中的交互作用研究. 中华流行病学杂志 2006(12) | 仅题录 |

## 二、拿到补充材料后读出了什么

模型是**竞争风险的灵活参数化生存模型**（Royston–Parmar）。原文给的形式：

- 绝对风险：对肿瘤死亡风险 λ1 与「其他原因死亡」风险 λ2 做积分，带竞争风险生存项；
- 每个病因别模型：ln H_k(t | x) = s(ln t | γ, n0) + x β；
- 基线 log 累积风险是 **ln(t) 的限制性三次样条**，参数为 γ 与节点位置 n0。

## 三、为什么仍然不能算（关键证据）

1. **补充材料只公布 β，没有公布 γ 与节点位置。**
   Supplementary Table 2 是「其他原因死亡」模型，全文只有 4 行系数：
   年龄 β=0.0975、女性 β=-0.3459、既往吸烟 β=0.3543、现在吸烟 β=0.3461。
   而绝对风险必须知道样条基线（γ、n0），论文里没有给出数值。
2. **肿瘤死亡模型（ALARM-NS / ALARM-ES）的 β 在正文表格**，补充材料只给竞争风险那一半。
3. 缺 γ 时，任何「用 HR 反推个人概率」的做法都等于自己造基线 —— 那是编数据。

## 三·五、2026-11-06 更新：摘要已拿到，家族史那条给出相对风险

用 Europe PMC REST 接口取到了原文摘要（不是二手转述），数字如下（均校正吸烟等混杂）：

| 指标 | 结果 |
| --- | --- |
| 一级亲属有肺癌 | OR 1.51（95% CI 1.39–1.63） |
| 同胞患病 | OR 1.82（1.62–2.05） |
| 从不吸烟者 | OR 1.25（1.03–1.52） |

因此 `exposure.ts` 里的 `family-lung-history` 现在**给数字**，但仍坚持两条口径：
① 这是相对风险，不是个人绝对概率；② 不进 FINDRISC / China-PAR 任何评分。

绝对风险模型（CKB 的 ALARM）仍然**不可复现**（缺基线样条参数），结论不变。

## 四、结论

- **不实现数值模型**。要继续只有两条路：向作者索取模型对象/代码，或退一步只做**相对风险表述**。
- 界面维持现状：只给「一级亲属有肺部疾病 + 你在吸烟，这类组合值得与医生讨论筛查」的提示，并写明不给概率及原因。

## 五、可选的中间方案（未实施，需要决策）

用**已发表的相对风险**做相对比较：「文献报道这类组合的肺癌风险高于无家族史者」，给出 HR 与置信区间，
并注明「相对风险不等于个人绝对概率」。前提是先读到 2006 年那篇的原文效应量并登记；拿不到原文就仍不给。

## 2026-11-08 更新：绝对风险已经有解了

本文前面之所以只给相对风险、不给个人概率，是因为 CKB 的相互作用模型**不可复现**（只公布 β，缺基线样条）。

现在补上了一个**系数完整公开**的模型：**PLCOm2012**（Tammemägi 2013, NEJM；表 2 给了全部 β 与常数项，
表注给了中心化取值与吸烟强度的非线性变换）。它的变量里同时包含：

- **家族史肺癌**（β = 0.587185）
- **吸烟状态 / 强度 / 年限 / 戒烟年数**（其中强度走 1/x 非线性变换）

也就是说，"家里有肺癌史 + 本人吸烟 → 6 年风险"这条链，现在**能算出数**了，实现见
`src/lib/risk/plcom2012.ts` 与 `/lung` 页，台账见 `docs/references.md` 第四节。

**仍然保留的边界**：PLCOm2012 是人群模型，只对曾经吸烟者建模，55–74 岁之外表现不确定；
它不包含任何基因数据，所以"基因不好"在模型里的代理变量就是**家族史**这一项。
